# jodal — 오늘부터 조달청

조달청 업무를 소재로 한 비공식 HTML 시뮬레이션 게임 프로젝트입니다.

## 로컬 실행

- 빌드된 단일 파일: `today-pps/index.html` 을 브라우저로 엽니다.
- 소스 수정 후 재빌드: `node build-game.cjs` (루트의 `오늘부터_조달청.html` 갱신)

## GitHub Pages

- 계정: **ray0u0**
- 저장소: **jodal**
- 게임 URL: `https://ray0u0.github.io/jodal/` (`docs/index.html` 배포)

GitHub → **Settings → Pages → Build and deployment** 에서 Branch `main`, Folder `/docs` 를 선택하세요.

조달청 로고·나르미·달이 캐릭터 권리는 해당 권리자에게 있습니다. 공식 서비스가 아닙니다.
